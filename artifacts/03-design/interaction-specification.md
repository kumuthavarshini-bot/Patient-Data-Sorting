# Interaction specification

The existing dashboard uses keyboard-operable phase cards, approval checklists, local theme preference, search, and workflow JSON export. The Live Demo uses a local file picker/drop zone, preview, profiling, mapping confirmation, validation, output tabs, and downloads. The CLI requires a CSV path, mapping confirmation, and writes an evidence directory. Statuses in run evidence are computed by executed code; dashboard phase statuses remain local planning-prototype state and must not be read as runtime run state.
