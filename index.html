01 — The Problem

Too much time is spent locating the right patient data.

Healthcare teams work with large, complex datasets distributed across inconsistent files and fields. Manually filtering, sorting, matching and checking records slows delivery and leaves less time for decisions that matter.

01

High volume

Thousands of patient records are difficult to scan, compare and reconcile by hand.

02

Fragmented data

Divergent formats, missing fields and inconsistent labels make records harder to manage and trust.

03

Manual effort

Teams invest significant time filtering, sorting and checking data before it is usable.

The opportunity

Enable teams to find, understand and prepare the right patient records faster, with substantially less repetitive manual work.

03 — The Agents

Five specialised agents. One coherent workflow.

Each agent owns one well-defined responsibility; the orchestrator passes each output forward.

AgentResponsibilityOutput
01  ProfileScans the source file to assess columns, formats, missing values and overall data quality.Data profile of the incoming file
02  MappingMatches source columns to the target patient-data schema and flags low-confidence matches.Proposed field mapping
03  NormalizationStandardises approved formats such as dates, phone numbers and text values.Consistently formatted dataset
04  ValidationChecks required fields, duplicate IDs, data types and configured business rules.Pass/fail results with reasons
05  ExceptionGroups failed records, explains what requires attention and generates a correction report.Exception file and recovery path
Human in control. Uncertain mappings and material corrections are surfaced for review rather than silently assumed.

The gate model describes the presentation’s target workflow. The current demo has no import destination; its CLI explicitly blocks at import.

05 — The Solution

Less sorting. More understanding.

A conversational assistant gives users a simpler way to explore results, while the pipeline handles repeatable checks and preparation.

Ask in plain language

“Which records are missing required fields?”“Why did this record fail?”“Which columns still need mapping?”

Receive actionable guidance

Summarises errors, explains validation outcomes and directs users to the next step, without fabricating patient data.

Keep the rules in control

Deterministic checks decide pass or fail. The assistant explains results; it never overrides validation or silently alters records.

The differentiator

A guided, auditable workflow — not merely a chatbot or a file upload.

Agents reduce repetitive profiling, mapping and checking. Review gates protect data quality. The assistant helps people understand results and act faster.

Intended impact

  • Less manual filtering and sorting
  • Faster identification of data issues
  • Clearer recovery from errors
  • More time for meaningful work

Measurement. Success will be assessed on live runs: processing time, records flagged, mapping corrections, import eligibility and user feedback. Time savings will be reported only once measured.

In the current Live Demo, Ask DataCare uses approved static Q&A and does not inspect uploaded records or decide validation outcomes. The live workflow processes customer CSVs locally; it is not approved for patient or PHI data.
