06

Processing and validation results

Illustrative rules

Original source cells are retained beside canonical values. Customer ID absence and same-batch duplicates are blocking checks. A basic email check and non-ISO date screening are review-only; no date conversion occurs. Whitespace trimming and email lowercasing are applied only when explicitly approved in this page session. Tokens such as N/A and NULL remain literal text. This demo does not import records.

“Valid” means no configured blocking or review finding was raised by this demo. It is not an import approval or production validation result. Formula-like cells are prefixed in CSV downloads to reduce spreadsheet formula execution risk; in-memory source values remain unchanged.
